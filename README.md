# motoshop-frontend

Фронтенд интернет-магазина мототехники, экипировки и запчастей: каталог товаров, корзина, оформление заказов, личный кабинет и панель администрирования.

Бэкенд проекта: [motoshop-backend](https://github.com/ItzDeVeR/motoshop-backend)

## Стек
- Vue 3, Vite
- PrimeVue
- Tailwind CSS
- Pinia / Vue Router
- Axios

## Установка и запуск

1. Установка зависимостей:
```bash
npm install
```

2. Настройка переменных окружения:
Создайте файл `.env` (на основе `.env.example`):
```env
VITE_API_URL=http://localhost:3000
```

3. Запуск dev-сервера:
```bash
npm run dev
```

Сборка проекта:
```bash
npm run build
```
